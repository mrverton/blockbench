# Blockbench внутри Telegram — готовые файлы

Этот архив **не содержит весь Blockbench**: он содержит дополнения для
официального Fork https://github.com/JannisX11/blockbench.
Всё для запуска самого редактора подготовлено; API можно подключить позднее.

## Самый короткий путь: GitHub → Vercel → Telegram

1. Зарегистрируйся на https://github.com и открой https://github.com/JannisX11/blockbench.
2. Нажми **Fork** → **Create fork**, чтобы создать свою копию репозитория.
3. Скачай форк на компьютер (GitHub → Code → Download ZIP) и распакуй; или
   выполни `git clone https://github.com/ТВОЙ_USERNAME/blockbench.git`.
4. Скопируй содержимое ЭТОГО архива в корень своего проекта `blockbench/`:
   - `vercel.json`
   - папку `scripts/`
   - папку `telegram/`
   - папку `backend/` (необязательна для открытия редактора)
   - `README_RU.md`
   Не удаляй существующие папки Blockbench.
5. Если используешь git, выполни `git add . && git commit -m "Add Telegram Mini App" && git push`.
   Если без git: в репозитории GitHub нажми **Add file → Upload files** и
   загрузи добавленные файлы, сохранив структуру папок. Нажми **Commit changes**.
6. Открой https://vercel.com/new, войди с GitHub, выбери свой форк Blockbench.
   **Framework Preset:** Other. Конфигурация сборки уже в `vercel.json`.
   Нажми **Deploy** и дождись зелёного статуса. Получишь HTTPS-ссылку вида
   `https://имя.vercel.app`. Открой её в обычном браузере и проверь редактор.
7. В Telegram открой официального @BotFather, отправь `/newbot` и создай бота.
   НЕ отправляй никому полученный токен бота.
8. Отправь `/newapp`, выбери этого бота, укажи название/описание и HTTPS-ссылку
   Vercel. Придумай короткое имя `editor`.
9. BotFather выдаст прямую ссылку типа `https://t.me/YourBot/editor`.
   Отправь её другу: при открытии в Telegram появится Blockbench!

Если сайт показывает ошибку сборки, открой Vercel → Project → Deployments →
Failed Deployment → Build Logs. Пришли текст ошибки без секретных токенов.

## Что уже настроено

- Скрипт `telegram/telegram-init.js` вызывает `ready()`, `expand()`,
  `disableVerticalSwipes()` и подтверждение закрытия приложения.
- Сборка `scripts/telegram-miniapp-build.mjs` копирует статические файлы
  Blockbench в папку `public/`, а также автоматически вставляет нужные скрипты
  в `index.html` собранного сайта. Оригинал `index.html` не меняется.
- Плагин `telegram/export-plugin.js` добавляет пункт **Telegram → Отправить
  модель на сервер**. Он отправляет .bbmodel с текстурами и signed `initData`.
- Без API редактор всё равно полностью открывается. Кнопка отправки модели
  сообщит, что адрес backend ещё не настроен.
- В `backend/` лежит FastAPI-сервер и отдельная инструкция его запуска.

## Чтобы подключить сервер сохранения 3D-моделей

Сначала разверни и запусти `backend/main.py` (см. `backend/README.md`). Затем
открой `telegram/config.js`, подставь HTTPS-адрес своего API и обнови сайт.
Токен Telegram-бота хранится ТОЛЬКО в переменной окружения `BOT_TOKEN`
Python-сервера. В клиентские файлы этот токен НЕ вставляй.

  из оригинального репозитория, соблюдай условия лицензии при публикации форка.
